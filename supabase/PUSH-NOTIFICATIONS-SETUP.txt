ATHAR — تنبيهات الجوال (Web Push) — الإعداد النهائي
═══════════════════════════════════════════════════════════════════════════

المسار العامل: التطبيق → violation-push → أجهزة المشتركين (عند رصد مخالفة).

1) SQL (مرة واحدة)
   supabase/push_notifications.sql

2) Secrets في Supabase → Edge Functions
   VAPID_PUBLIC_KEY  = نفس ATHAR_VAPID_PUBLIC_KEY في index.html
   VAPID_PRIVATE_KEY = المفتاح الخاص المقترن
   VAPID_SUBJECT     = mailto:admin@athar.app

3) نشر الدالة violation-push
   تلقائياً: GitHub Action (يحتاج SUPABASE_ACCESS_TOKEN في secrets المستودع)
   يدوياً: npx supabase functions deploy violation-push --no-verify-jwt

4) الجوال
   • أضف الموقع للشاشة الرئيسية (PWA) — خاصة iPhone
   • قائمة المستخدم → تفعيل تنبيهات الجوال

5) من يستلم التنبيه؟
   • الموظف المعني
   • مدير فرع نفس الفرع (مع اسم الموظف)
   • مشرف المنطقة (مع اسم الموظف)

6) إن شغّلت سابقاً violation-push-trigger.sql
   شغّل: supabase/إزالة-trigger-التنبيهات-إن-وُجد.sql
   (لتجنب إشعار مكرر)

تحقق: https://rizoafuxmqsddjfhbsmf.supabase.co/functions/v1/violation-push
       يجب vapidConfigured:true و vapidValid:true
