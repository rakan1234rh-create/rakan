ATHAR — تفعيل تنبيهات الجوال خارج التطبيق (Web Push)
═══════════════════════════════════════════════════════════════════════════

1) SQL
   شغّل: supabase/push_notifications.sql في SQL Editor
   تحقق: supabase/تحقق-التنبيهات-الخارجية.sql — يجب أن يظهر اشتراكك بعد التفعيل

   ملاحظة: ملف sw.js يُنسخ تلقائياً مع النشر (GitHub Pages). إن ظهر 404 عند التفعيل
   انتظر اكتمال نشر آخر push أو افتح: https://your-domain/sw.js يدوياً للتأكد.

2) مفاتيح VAPID (مرة واحدة)
   من جهازك:
     npx web-push generate-vapid-keys

   في Supabase → Project Settings → Edge Functions → Secrets:
     VAPID_PUBLIC_KEY  = المفتاح العام
     VAPID_PRIVATE_KEY = المفتاح الخاص (لا ترفعه على GitHub)
     VAPID_SUBJECT     = mailto:your-email@example.com

   ⚠ المفتاح العام في Secrets يجب أن يطابق index.html:
     ATHAR_VAPID_PUBLIC_KEY
   إن اغيّرت المفاتيح أعد «تفعيل تنبيهات الجوال» من القائمة.

3) نشر الدالة (إلزامي — بدونها لن يصل أي تنبيه من الخادم)
     npx supabase@latest login
     npx supabase@latest link --project-ref rizoafuxmqsddjfhbsmf
     npx supabase@latest functions deploy violation-push --no-verify-jwt

   تحقق: افتح في المتصفح
     https://rizoafuxmqsddjfhbsmf.supabase.co/functions/v1/violation-push
   يجب أن يظهر {"ok":true,"service":"violation-push",...}
   إن ظهر 404 فالدالة غير منشورة بعد.

4) Database Webhook (Supabase Dashboard)
   Database → Webhooks → Create hook
   • Name: violation-push
   • Table: violations
   • Events: Insert
   • Type: Supabase Edge Function
   • Function: violation-push
   • HTTP Headers (أحد الخيارين):
     Authorization = Bearer <SERVICE_ROLE_KEY>
     — أو —
     x-athar-push-secret = <قيمة سرية>
     وأضف نفس القيمة في Secrets: PUSH_WEBHOOK_SECRET

5) اختبار من التطبيق (بعد النشر)
   • سجّل دخول من الجوال
   • قائمة المستخدم → «تفعيل تنبيهات الجوال» → اسمح بالإشعارات
   • نفس القائمة → «اختبار تنبيه الجوال»
   • إن ظهر خطأ، اقرأ الرسالة (جدول ناقص / VAPID / الدالة غير منشورة)

6) الجوال
   • أضف الموقع إلى الشاشة الرئيسية (PWA)
   • iOS 16.4+: التنبيهات تعمل فقط للتطبيق المثبّت على الشاشة الرئيسية
   • Android Chrome: يعمل من المتصفح أو PWA
   • Safari على سطح المكتب: لا يدعم Web Push

7) من يستلم التنبيه عند رصد مخالفة؟
   • الموظف المعني (employee_id)
   • مدير فرع نفس الفرع
   • مشرف المنطقة
   ملاحظة: من يسجّل المخالفة بنفسه قد لا يكون ضمن المستلمين.

8) تشخيص سريع
   ┌─────────────────────────────────────┬──────────────────────────────────┐
   │ العرض                               │ السبب المحتمل                    │
   ├─────────────────────────────────────┼──────────────────────────────────┤
   │ فشل حفظ الاشتراك / جدول غير موجود   │ لم يُشغَّل push_notifications.sql │
   │ لم يُرسل: no push_subscriptions     │ التفعيل من الجوال لم يُحفظ في DB  │
   │ لم يُرسل: VAPID keys not configured │ Secrets ناقصة في Edge Functions  │
   │ unauthorized من Webhook             │ Authorization أو PUSH_WEBHOOK    │
   │ الاختبار ينجح لكن المخالفة لا       │ Webhook غير مربوط على violations │
   └─────────────────────────────────────┴──────────────────────────────────┘

   سجلات الدالة: Supabase → Edge Functions → violation-push → Logs
